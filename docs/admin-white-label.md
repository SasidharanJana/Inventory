# Admin Console & White-Label Capabilities

## Multi-Tenant Admin Console
- **Tenant Management**: provisioning, lifecycle, usage, billing.
- **Configuration Studio**: industry templates, dynamic fields, workflow rules.
- **Access Control**: role templates, SSO/SAML, MFA, IP allowlists.
- **Audit & Compliance**: logs, exports, retention policies.

## White-Labeling
- **Branding**: logos, color themes, custom domains, email templates.
- **Feature Flags**: per-tenant product edition and add-on modules.
- **Reseller Portal**: manage sub-tenants, quotas, and pricing.

## Deployment Modes
- **SaaS**: shared infrastructure with tenant isolation.
- **Private Cloud**: dedicated tenant environments.
- **On-Prem**: enterprise deployment with offline support.

## Tenant Onboarding Flow
1. Select industry template.
2. Configure locations, taxes, units, and currencies.
3. Import master data (items, customers, suppliers).
4. Assign roles and dashboards.
5. Enable modules and automations.
